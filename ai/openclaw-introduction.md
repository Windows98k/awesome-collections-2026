# OpenClaw 介绍与使用笔记

## 项目概述
OpenClaw 是 2026 年非常热门的本地个人 AI 助手项目。

**核心特性：**
- 支持完全本地运行
- 多平台支持（Windows / macOS / Linux）
- 兼容多种大模型
- 强调隐私保护

## 快速开始

```bash
git clone https://github.com/openclaw/openclaw.git
cd openclaw
# 按照 README 安装
```
